Тест-кейсы

TC-01 — Создание задачи (нормальный сценарий)
Предусловия:
Программа установлена, файл данных отсутствует или пустой
Шаги:
Запустить программу
Ввести команду создания задачи
Ввести название: "Купить хлеб"
Ввести описание: "После работы"
Ожидаемый результат:
Задача создаётся и отображается в списке
Есть ID и статус (например, new)
Постусловия:
Задача сохранена в памяти программы

TC-02 — Создание задачи с пустым названием (ошибка)
Предусловия:
Программа запущена
Шаги:
Ввести команду создания задачи
Оставить название пустым
Ввести описание
Ожидаемый результат:
Программа выдаёт ошибку
Задача НЕ создаётся
Постусловия:
Список задач не изменился
